# MODLOG — журнал Villager Life

Журнал в формате universal-modder: версии, маршрут, оракулы, что не вышло и почему, следующий шаг. Новое — сверху,
с датой. Устройство мода и правила не повторяем: они в `AGENTS.md` (там же раздел «Найдено живой проверкой» —
главный список граблей). Состояние — `STATUS.md`.

## 21.10.2026 — чистая комната: код реплик с нуля, MIT
- Код, унаследованный от прежнего Java-порта (без лицензии), переписан с нуля, своим устройством: вместо одного
  контроллера на 3300 строк — `Speech` (сказать реплику, кулдауны, «один голос на округу»), `SpeechQueue`, `Voices`,
  `VillagerTalk` (события, тик) и реакции по темам (`PlayerWatch`, `Surroundings`, `WorldEvents`, `Harm`, `Conditions`,
  `VillagerMoments`, `Chats`, `Trades`, `Bedtime`); таблицы заголовков — данными (правила «id → заголовок»). Переписаны
  `DialogueCatalog`, `/dialoguetest` (проще: сцена по голосу группы и мобу из заголовка), клиентский звук и субтитры,
  настройки (`LifeSettings*`, `LifeClientSettings`), `VillagerDataMixin`/`VillagerLifeData`, миксины звуков
  (`MerchantVoiceMixin`), сделки — событием NeoForge. Старый справочник (`HandbookScreen`, `handbook.json`) заменён
  `SettingsScreen` и `ReactionsScreen` (каталог реакций прямо из `dialogues.json`).
- Убраны особые персонажи (Testificate Man, №5, №9, Unreachable, Wooly: голоса, спавн и настройка `spawnSpecialVillagers`),
  косметика, носы и табличка в руках жителя (данные на жителе тоже). Мэр ничего не продаёт.
- Сравнение с прежним кодом по строкам: в контроллере было 1852 общих строки из 2405, в новых классах — 114 из 1847
  (вызовы API игры, id реплик). `LICENSE` — MIT, s00d, с разделом о сгенерированных ассетах; `LICENSE-PORT` удалён.
- Проверка: `build` 1.21.1 зелёный, GameTests 291/291 (`gts_shards.py 4`), 1.21.11 и 26.3 компилируются.

- Маршрут: свежие деревни «Нового мира» (`fresh.py`, по трое суток, потом короткие прогоны: сутки и гроза), лог `vnap death|monster|siege|slow`, профиль (`jstack` во время перемотки).
